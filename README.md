# 🍔 Food Delivery Website – React.js

A modern and fully responsive Food Delivery Web Application built using **React.js**. This project provides an intuitive user interface where users can explore food items, browse categories, add products to their cart, and manage their food orders.

The application uses **Context API and Redux Toolkit** for state management, ensuring a smooth and organized user experience.

## ✨ Features

- **Responsive Design:** Works smoothly on desktop, tablet, and mobile devices.
- **Food Browsing:** Explore different food items.
- **Food Categories:** Browse food according to categories.
- **Shopping Cart:** Add and remove food items from the cart.
- **Quantity Management:** Increase or decrease product quantities.
- **State Management:** Context API and Redux Toolkit.
- **Reusable Components:** Modular and reusable React components.
- **Interactive UI:** Clean and user-friendly interface.
- **Modern Styling:** Attractive and responsive layouts.

## 🧠 State Management

This project uses two state management approaches:

**Context API**
- Shares data between components.
- Avoids unnecessary prop drilling.
- Manages shared application state.

**Redux Toolkit**
- Manages centralized application state.
- Uses slices and reducers.
- Simplifies state updates.
- Makes application state predictable and maintainable.
